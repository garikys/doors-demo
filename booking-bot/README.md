# Бот записи для Telegram и MAX

Демо-проект: бот онлайн-записи в барбершоп. Один сценарий работает сразу в двух мессенджерах.

**Что умеет**
- выбор услуги, мастера, дня и свободного времени;
- занятые слоты скрываются автоматически, двойная запись невозможна;
- «Мои записи» с отменой в один клик;
- уведомление администратору о каждой записи и отмене;
- цены и адрес салона.

**Устройство**
- `core.py` — сценарий и база записей (SQLite), не зависит от мессенджера;
- `tg_bot.py` — адаптер Telegram (aiogram 3);
- `max_bot.py` — адаптер MAX (maxapi).

Услуги, мастера и часы работы меняются в начале `core.py`.

**Запуск**
```
pip install -r requirements.txt
TG_TOKEN=... TG_ADMIN_CHAT_ID=... python tg_bot.py
MAX_TOKEN=... MAX_ADMIN_CHAT_ID=... python max_bot.py
```
Токен Telegram выдаёт @BotFather, токен MAX — @MasterBot (создание ботов в MAX доступно подтверждённым организациям).
